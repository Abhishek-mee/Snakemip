# Snake

the Snake game it is not that much hard to make it.


## Play

- **Arrow keys** or **WASD** — move
- **Space** — pause / resume
- **Enter** — start / resume
- **R** — restart
- On touch devices, swipe on the board or use the on-screen D-pad.
